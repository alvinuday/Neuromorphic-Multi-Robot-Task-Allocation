\section{The Problem: Hardware Limitations in Robotics}

Modern robotics demands real-time optimization: which robots form coalitions for tasks, and how do they execute commands within milliseconds. Classical CPU-based approaches timeout. This thesis demonstrates neuromorphic hardware as a solution.

\section{Two Hardware Approaches}

\subsection{Coalition Task Allocation via OIM}

The Oscillator Ising Machine (OIM) solves combinatorial optimization by encoding problems as oscillator networks. For multi-robot coalitions, we:
\begin{enumerate}
\item Formulate coalition selection as Maximum Weight Independent Set (MWIS)
\item Convert MWIS to QUBO (Quadratic Unconstrained Binary Optimization)
\item Map QUBO to Ising Hamiltonian
\item Solve on OIM hardware in 12--15 milliseconds
\end{enumerate}

Key result: 92\% approximation ratio with 100\% feasibility.

\subsection{Model Predictive Control via SNN}

Spiking Neural Networks (SNNs) implement iterative optimization algorithms like PIPG (Proportional-Integral Projected Gradient). For robot arm control:
\begin{enumerate}
\item Linearize robot dynamics around equilibrium
\item Formulate MPC as constrained QP
\item Map PIPG iterations to SNN spike patterns
\item Achieve 20 millisecond convergence
\end{enumerate}

Key result: $>100\times$ energy-delay improvement vs CPU.
