\section{Overview: Three Converging Frontiers}
\begin{block}{warning}
Three separate research threads (Ising machines, multi-robot coordination, neuromorphic computing) converge here. This is not coincidence—each solves a piece of the same puzzle.
\end{block}


This chapter surveys three converging frontiers: Ising machines, multi-robot task allocation, and neuromorphic computing. Their combination is novel.

\section{Frontier 1: Ising Formulations}

The Ising model (1925) encodes binary optimization as spin configurations:
\[
H = \sum_i h_i s_i + \sum_{i<j} J_{ij} s_i s_j
\]

Lucas (2014) proved NP-hard problems map to Ising: Max Weighted Independent Set, clique, graph coloring, constraint satisfaction. Finding the ground state solves the original problem. This universality is key: quantum computers, photonic processors, and neuromorphic hardware all exploit it.

Coalition allocation, scheduling, and graph optimization map naturally to Ising. The advantage: hardware whose physical dynamics directly solve the problem, not simulating algorithms on digital silicon.

\section{Oscillator Ising Machines}

OIMs use coupled oscillators (not digital simulation) to physically solve Ising problems. Kuramoto (1984) modeled phase synchronization; Wang and Roychowdhury (2019) extended this to combinatorial optimization. Oscillators with phases $\theta_i$ synchronize toward minima of the Ising Hamiltonian. Key properties: solutions emerge from physical dynamics (no algorithm loops), nanosecond-scale switching, sub-milliwatt power, 37--60\% first-pass success on dense graphs, scalable to 100+ nodes. Unlike quantum annealing, OIM provides real-time deterministic solutions.

\section{Multi-Robot Task Allocation}

MRTA (Gerkey & Matarić, 2004) is NP-hard: 20 robots × 10 tasks = $2^{200}$ allocations. Exact solvers (MILP, branch-and-bound) timeout on realistic instances. Classical approaches:
\begin{itemize}
\item Exact: $O(2^N)$, optimal, $< 20$ robots
\item Greedy: $O(N^2M)$, approximation, 100+ robots
\item Market-based / Constraint Programming: approximate, distributed
\end{itemize}
OIM offers $O(1)$ real-time deterministic solutions, scaling to 100+ robots with guarantees.

\textbf{Why classical approaches struggle:} Exact solvers (integer linear programming, branch-and-bound) guarantee optimality but timeout on real-time constraints. Greedy algorithms run quickly but produce suboptimal allocations, wasting robot capability. Market-based approaches distribute allocation but require negotiation overhead and often converge slowly. Constraint programming approaches are flexible but still impose significant computational cost on embedded hardware. For a warehouse operating at 50 Hz (20 ms decision window), none of these meet the hard real-time constraint while maintaining good quality.

\textbf{The neuromorphic solution:} OIM offers a fundamentally different approach. Rather than iterating toward a solution through algorithm steps, OIM exploits the physics of coupled oscillators to find approximate solutions in microseconds to milliseconds. This speed-quality-energy trade-off is precisely what real-time robotics needs: fast enough to meet timing constraints, good enough to maintain solution quality, and efficient enough to run on battery power.

\textbf{Gap:} No prior work applies OIM (or neuromorphic hardware generally) to MRTA. Classical approaches timeout on real-time constraints; neuromorphic approaches promise millisecond solves with hardware energy efficiency. Our contribution bridges this gap with mathematical validation, algorithmic mapping, and experimental proof.

\section{Model Predictive Control}
\begin{block}{warning}
MPC solves a constrained optimization problem at every time step. If neurons can optimize, they can implement MPC. If we engineer it right.
\end{block}


\subsection{MPC Fundamentals}

Model Predictive Control (MPC) \cite{Rawlings2020} is the dominant control strategy in industry and robotics. The core approach:
\begin{itemize}
\item At each time step, solve an optimization problem over a receding horizon (10--20 steps ahead)
\item Execute the first computed control action, then replan at the next step
\item Naturally handles constraints (torque limits, position bounds)
\item Previews future disturbances for complex trajectory tracking
\end{itemize}

Mathematically, at time $t$ solve:
\[
\min_{u_{t:t+N}} \sum_{i=0}^{N-1} \left( \|x_{t+i} - x_*\|_Q^2 + \|u_{t+i}\|_R^2 \right) \quad \text{subject to} \quad x_{t+i+1} = Ax_{t+i} + Bu_{t+i}, \; u_{\min} \le u_{t+i} \le u_{\max}
\]

This is a quadratic program (QP) that must solve at every control cycle.

\subsection{Real-Time Computational Bottleneck}

Classical MPC requires solving QPs with 1--100 ms latency using OSQP \cite{Stellato2018} or Mosek. For real-time control (10--20 ms cycle times):
\begin{itemize}
\item Robot arm at 50 Hz has 20 ms decision window
\item Spending 10--50 ms per solve leaves no margin for sensing delays or communication overhead
\item Embedded hardware constraints make classical solvers prohibitive
\end{itemize}

\subsection{Neuromorphic Solution Approach}

Iterative optimization methods for MPC include:
\begin{itemize}
\item Gradient descent \cite{Nesterov2018}
\item Proximal methods \cite{Boyd2010}
\item PIPG (Proportional-Integral Projected Gradient) \cite{He2016}: achieves exact solutions in $O(\log(1/\epsilon))$ iterations
\end{itemize}

Each iteration computes simple operations: $v_{k+1} = \alpha(x_k - x_*) - \beta \nabla \mathcal{L}(u_k)$ where $\alpha, \beta$ are gains. These are exactly the computations spiking neurons implement naturally through spike-based integration and firing thresholds.

\textbf{Why neuromorphic works:} Traditional CPUs process iterations sequentially, with memory access dominating energy cost. Spiking neurons integrate inputs locally (at synapses) and compute gradients implicitly (via thresholds), eliminating the Von Neumann bottleneck.

\textbf{Gap:} While algorithms like PIPG are mathematically suited for neural implementation, no prior work maps full MPC trajectories (multiple decision variables, constraints) to spiking neural networks with guaranteed convergence and real-time performance. Our SNN-MPC approach directly encodes PIPG iterations in spike patterns, achieving sub-mW power with millisecond solves while maintaining accuracy.

\section{Neuromorphic Computing Platforms}

Neuromorphic processors use event-driven spiking computation: neurons fire only when thresholds are crossed, avoiding the power waste of clocking every transistor at every cycle. Key platforms:

\begin{itemize}
\item \textbf{Intel Loihi}: 128 cores, 1 MHz clock, ~100 mW. Good for image processing; latency-critical robotics requires faster clocks.
\item \textbf{IBM TrueNorth}: 4,096 cores, 1 mW power. Ultra-efficient but fixed topology, limited reconfigurability.
\item \textbf{BrainScaleS-2}: Hybrid analog-digital, configurable plasticity. Research-grade, not deployed commercially.
\item \textbf{Vanadium Dioxide Oscillators}: GHz+ frequencies, picojoule switching. Core of OIM; nanosecond-timescale operations ideal for real-time robotics.
\end{itemize}

Mangalore et al. \cite{Mangalore2024} first demonstrated MPC on Loihi (20 ms convergence, 4-DOF arm). This thesis extends that work by combining task allocation (OIM) and control (SNN-MPC) with formal guarantees.
