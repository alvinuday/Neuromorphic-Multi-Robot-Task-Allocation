\section{Ising Formulations and Optimization}

The Ising model, originally proposed by Ernst Ising in 1925 \cite{Ising1925} as a model of ferromagnetism, has become a fundamental tool in optimization. Lucas (2014) \cite{Lucas2014} proved that many NP-hard problems (including Maximum Weighted Independent Set \cite{Kochenberger2014}, Maximum Clique, graph coloring) can be encoded as Ising Hamiltonians. An Ising model is a system of binary spins $s_i \in \{-1, +1\}$ with pairwise interactions:
\[
H = \sum_i h_i s_i + \sum_{i<j} J_{ij} s_i s_j
\]

Finding the ground state (minimum energy configuration) solves the original optimization problem. The relationship between classical QUBO (Quadratic Unconstrained Binary Optimization) \cite{Kochenberger2014} and Ising is bijective, making Ising machines universal NP-hard solvers. Recent work \cite{Kadowaki2012} has shown quantum annealing and related approaches can approximate solutions in the planted solution regime.

\section{Oscillator Ising Machines}

Coupled oscillator systems have roots in classical dynamical systems theory \cite{Kuramoto1984, Strogatz2000}. The Kuramoto model \cite{Kuramoto1984} describes phase synchronization in coupled oscillators, while Strogatz's work \cite{Strogatz2000} unified synchronization phenomena. Wang and Roychowdhury \cite{Wang2019, Wang2021} developed OIM (Oscillator Ising Machine) theory for combinatorial optimization on coupled networks. Key results:
\begin{itemize}
\item OIM dynamics: CMOS-compatible analog circuits with coupling and injection locking \cite{Bifrost2021}
\item Multi-start convergence: 37--60\% first-pass success on dense graphs, increasing with restarts
\item Scalability: linear time O(N) per iteration, up to 100+ nodes with edge pruning \cite{Wang2019}
\item Hardware: VO$_2$ (vanadium dioxide) oscillators reaching nanosecond switching speeds \cite{Cederberg2012}
\end{itemize}

Unlike quantum annealing, OIM provides deterministic trajectories in real time, avoiding the measurement-and-collapse overhead of quantum systems.

\section{Multi-Robot Task Allocation}

Multi-robot task allocation (MRTA) is a foundational problem in multi-agent systems \cite{Khamis2015}. Gerkey and Matarić \cite{Gerkey2004} established the MRTA taxonomy, categorizing algorithms by whether robots are heterogeneous, tasks are atomic or complex, and agent knowledge is global or local. Coalition formation (our focus) is NP-hard in general \cite{Sandholm2002}, making approximation algorithms and heuristics essential.

Prior solution approaches include:
\begin{itemize}
\item Exact solvers: Dynamic programming or branch-and-bound, exponential time $O(2^N)$, limited to $<20$ agents \cite{Korsah2012}
\item Greedy allocation: O(N$^2$M) time, near-optimal on special structures (trees, bipartite graphs) \cite{Gerkey2004}
\item Market-based / Auction methods: Asynchronous decentralized convergence, price-based bid mechanisms \cite{Zlot2002, Nanjanath2010}
\item Distributed constraint programming: Scalable to 100+ agents with communication overhead \cite{Korsah2012}
\end{itemize}

\textbf{Gap:} No prior work applies OIM (or neuromorphic hardware generally) to MRTA. Classical approaches timeout on real-time constraints; neuromorphic approaches promise millisecond solves. Our contribution bridges this gap with theoretical guarantees and experimental validation.

\section{Model Predictive Control}

Model Predictive Control (MPC) \cite{Rawlings2020} is the dominant control strategy in industry and robotics, solving a constrained optimization problem at each time step:
\[
\min_u \|x - x_*\|^2 + \|u\|^2 \quad \text{subject to} \quad Ax + Bu = x_{next}
\]

Classical MPC requires solving quadratic programs (QPs) with 1--100 ms latency on embedded hardware using algorithms like OSQP \cite{Stellato2018} or Mosek. For real-time robotic control (10--20 ms cycle times), this overhead is significant.

Iterative optimization methods for MPC include gradient descent \cite{Nesterov2018}, proximal methods \cite{Boyd2010}, and the PIPG (Proportional-Integral Projected Gradient) algorithm \cite{He2016}, which achieves exact solutions with $O(\log(1/\epsilon))$ iterations. Each iteration performs simple arithmetic operations amenable to neural network implementation.

\textbf{Gap:} While algorithms like PIPG are mathematically suited for neural implementation, no prior work maps full MPC trajectories (multiple decision variables, constraints) to spiking neural networks with guaranteed convergence. Our SNN-MPC approach directly encodes PIPG iterations in spike patterns, achieving sub-mW power with millisecond solves.

\section{Neuromorphic Computing Platforms}

Neuromorphic processors implement brain-inspired principles of spiking computation, achieving orders of magnitude improvements in energy efficiency \cite{Furber2016, Indiveri2015}. Major platforms include:

\begin{itemize}
\item \textbf{Intel Loihi \cite{Davies2018}}: Event-driven spiking neural cores, 128 Loihi cores per chip (1M synapses total), 1 MHz clock, ~100 mW active power. First deployed neuromorphic chip at scale.
\item \textbf{IBM TrueNorth \cite{Merolla2014}}: 4,096 neurosynaptic cores, 5.4B transistors, 1 mW active power, fixed-topology neurons with STDP learning.
\item \textbf{BrainScaleS-2 \cite{Müller2023}}: Hybrid digital-analog neurons on Heidelberg University's platform, configurable plasticity, wafer-scale prototypes.
\item \textbf{Vanadium Dioxide (VO$_2$) Oscillators \cite{Cederberg2012}}: Sub-threshold analog oscillators reaching GHz+ frequencies with picojoule switching energies, enabling 100+ node systems.
\end{itemize}

Recent neuromorphic benchmarks include image classification \cite{Bagheri2018}, sparse coding \cite{Indiveri2015}, and optimization \cite{Mangalore2024}. Mangalore et al. \cite{Mangalore2024} first demonstrated real-time MPC on Intel Loihi, achieving 20 ms convergence for 4-DOF arm control. Our work extends this framework by directly encoding both task allocation and control on a unified neuromorphic architecture.
