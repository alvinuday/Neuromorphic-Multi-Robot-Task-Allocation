Ising Hamiltonian H

H = Σᵢ hᵢsᵢ + Σᵢ＜ⱼ Jᵢⱼsᵢsⱼ. Bias fields hᵢ determine single-spin preference; coupling Jᵢⱼ > 0 means anti-ferromagnetic (spins want to be opposite).

Bias Fields hᵢ (selection pressure)
h_i = −w_i/2 + λ·deg(i)/4
Blue: prefers s=+1 (select)
Red: prefers s=−1 (skip)
Ising Parameters
h_i = −w_i/2 + λ·d_i/4
J_ij = λ/4 · 𝟏[(i,j)∈E]

K_ij(OIM) = −J_ij
I_bias,i = −h_i
Coupling Matrix J (symmetric conflict graph view)
J_ij > 0 (amber) = anti-ferromagnetic coupling = conflict → spins prefer anti-parallel → at most one active. J_ij = 0 = no coupling.
