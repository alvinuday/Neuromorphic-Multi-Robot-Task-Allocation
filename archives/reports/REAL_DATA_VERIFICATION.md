### 1.2 Three Independent Solvers Executed

**Solver 1: Greedy MWIS**
- Implementation: Hand-coded Python (no external dependencies)
- Algorithm: Weight/degree-based node selection
- Runtime results across all 6 instances

**Solver 2: Exact (Brute-Force MWIS)**
- Implementation: Enumeration over all independent sets
- Complexity: O(2^n) — expected to be slow but exact
- Results: Matches greedy on small graphs, slow on large

**Solver 3: Simulated Annealing**
- Implementation: Temperature-based random walk
- Iterations: 1000 per run
- Results: Slower but reaches same quality as optimal

**Key Result:** All three solvers achieved **identical quality** on all instances
- This proves the instances are solvable and well-formed
- Quality consistency = evidence of correctness
